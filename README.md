# Used Car Price Prediction

My first machine learning project for exploring used car listings and predicting vehicle prices.

## Project contents

- `notebooks/01_used_car_prediction.ipynb` contains exploratory analysis and model development.
- `data/` is reserved for local dataset files and is excluded from Git.

## Getting started

Create and activate a virtual environment, install Jupyter and the libraries used by the notebook, then start Jupyter:

```bash
python -m venv .venv
# Activate the environment, then install the notebook dependencies.
jupyter notebook
```

The dataset is not included in this repository. Obtain it from its original source, review its license and redistribution terms, and place an authorized copy in `data/` before running the notebook.

## Status

This project is a work in progress. Model methodology and results will be documented as development continues.
